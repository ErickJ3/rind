# libcrun compiled-source list

This file enumerates every `vendor/crun-1.23/src/*.c` and
`vendor/crun-1.23/libocispec/**/*.c` translation unit that
`build.zig`'s `cLibcrun` helper feeds to the static `libcrun.a` we ship.

The CLI half (`vendor/crun-1.23/src/{crun,run,create,start,exec,kill,
delete,list,pause,unpause,update,state,checkpoint,restore,run_create,
spec,oci_features}.c`) is **not** vendored — that half is GPL-licensed
upstream and rind never invokes it.

The audit script `scripts/lgpl_audit.sh` greps the SPDX header on every
file under `vendor/crun-1.23/src/` and flags any GPL-only file it finds
in **this** list as a BLOCKER. Keep the two lists synchronised.

## libcrun handlers (`src/handlers/`)

- `handlers/handler-utils.c`
- `handlers/exec.c`         (the in-process exec dispatch — required)

The wasm/lua/krun/spin/mono handlers in `src/handlers/` (`wasmer.c`,
`wasmtime.c`, `wasmedge.c`, `wamr.c`, `krun.c`, `spin.c`, `mono.c`) are
compiled but their feature toggles are 0; the dispatch table just skips
them at runtime.

## OCI spec codegen (`libocispec/src/ocispec/`)

The exact file list is build-determined: every `.c` directly under
`vendor/crun-1.23/libocispec/src/ocispec/` whose name ends in `_schema.c`
or `_defs.c` is compiled. The headers in the same directory are the
public include surface (`#include <ocispec/...>` from libcrun).

Auto-generated by `libocispec`'s codegen at upstream release time;
license inherits from `vendor/crun-1.23/libocispec/COPYING` (Apache-2.0).
