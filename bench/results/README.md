# results/

`latest.md` is regenerated by `just bench` (or `bash bench/run-all.sh`). Don't hand-edit.

`history/<date>_<sha>.md` is created by `just bench-snapshot` — pin a baseline before merging perf-relevant changes so regressions are visible in `git diff`.

`.raw/` (gitignored) holds the raw poop output and per-iter timing dumps for debugging the markdown generator.
